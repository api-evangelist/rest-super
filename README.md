Rest Super is the brand of the Retail Employees Superannuation Trust (Rest), an Australian profit-to-member superannuation fund serving around 2 million members, with Retail Employees Superannuation Pty Limited (ABN 39 001 987 739, AFSL 240003) as trustee. It offers Rest Super, Rest Corporate and Rest Pension products, retirement and advice services, and the Rest Pay employer contribution platform with published user guides. Its public web presence (rest.com.au) has no published developer API or portal; it was surfaced via the API Evangelist harvest backlog (australia-apidays-2026).

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Rest Super: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
